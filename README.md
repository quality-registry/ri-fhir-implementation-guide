# RES-Q FHIR Implementation Guide

Este es el repositorio del RES-Q FHIR Implementation Guide.

## Sitio publicado

El Implementation Guide se publica automáticamente en:
- **URL personalizada**: https://www.tecnomod-um.org
- **URL de GitHub Pages**: https://tecnomod-um.github.io/RESQFHIR-IG

## Configuración DNS

Para información sobre la configuración del dominio personalizado, consulta [DNS_SETUP.md](DNS_SETUP.md).

## Desarrollo

Este IG utiliza SUSHI para compilar los recursos FSH y el HL7 FHIR IG Publisher para generar el sitio web.
